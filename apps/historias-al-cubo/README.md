# Historias al Cubo

**Estado:** V4 aprobada.

## Objetivo

Juego digital de dados ilustrados para practicar narración oral, creatividad, conexiones de ideas y flexibilidad en mentorías de Tukana.

## Cómo utilizarlo

1. Seleccionar entre 1 y 5 dados.
2. Elegir una categoría: sorpresa total, aventura, fantasía, vida cotidiana o ciencia.
3. Pulsar **Lanzar dados**.
4. Pedir al estudiante que narre un cuento, encuentre conexiones entre los símbolos o cambie de perspectiva.
5. Se puede tocar un dado para volver a lanzar únicamente ese dado.

## Uso y privacidad

- No pide información del estudiante.
- No necesita iniciar sesión ni servidor.
- HTML, CSS y JavaScript integrados en un único archivo.
- No hay puntuación ni niveles. Se utiliza como actividad de conversación presencial.
