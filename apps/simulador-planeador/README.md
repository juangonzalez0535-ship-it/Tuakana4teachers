# Simulador de Planeador — Glider Lab

**Estado:** versión original de la sesión 2 de Aerospace Exploration.

Simulador visual para explorar de manera interactiva las fuerzas del vuelo y cómo cambian los resultados al modificar geometría del ala, masa, velocidad, forma del ala y centro de masa.

## Uso en clase

1. Formular una hipótesis: ¿qué cambiará si modificamos un parámetro?
2. Probar un solo cambio por vez en el simulador.
3. Observar las fuerzas, el movimiento y las líneas de flujo.
4. Comparar dos diseños y explicar cuál se comporta mejor y por qué.

## Consideraciones

Es una representación didáctica, no un simulador validado para diseñar aeronaves reales. No solicita datos personales. El archivo HTML original está conservado sin modificaciones en `index.html`.
