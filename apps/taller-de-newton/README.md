# Taller de Newton y fricción

App interactiva para estudiar las tres leyes de Newton, la fuerza neta y la fricción estática y cinética mediante explicaciones, simulación y cuatro misiones.

## Contenido

- **Aprende:** leyes de Newton, diagramas de cuerpo libre, fricción estática y cinética.
- **Experimenta:** controles de masa, fuerza, ángulo, coeficientes de fricción y velocidad inicial; muestra normal, fricción, aceleración inicial y distancia en 3 segundos.
- **Resuelve retos:** caja que no arranca, caja en movimiento, empujar frente a jalar y cuerda inclinada.

## Uso pedagógico

1. Pedir al estudiante una predicción antes de cada simulación.
2. Cambiar una variable a la vez para interpretar el efecto.
3. Justificar resultados usando el diagrama de cuerpo libre.
4. Usar los retos como verificación formativa.

## Supuestos del modelo

El modelo es didáctico, de un bloque deslizante sobre superficie horizontal, sin fuerzas adicionales, con gravedad 9,8 m/s². No representa inclinaciones del piso, rodadura, pérdida de contacto ni física de alta fidelidad. No necesita datos personales.

Referencia pedagógica: presentación «Leyes de Newton y fricción» (Gimnasio Vermont).
